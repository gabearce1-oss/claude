# /audit-doc

You are running an evidence-audit intake on the document referenced by `$ARGUMENTS` (path, filename, or descriptive name).

Run the `evidence-discipline` skill first if it isn't already active. Then walk the user through this intake — one question at a time, in this order. Wait for an answer before moving on:

1. **Document identity.** Confirm the document name and what kind of artifact it is (transcript, photo, deed, AI narrative, etc.). If `$ARGUMENTS` is a file path, read it first.
2. **Origin.** Was this document (a) transcribed from a primary archive, (b) compiled from existing research, (c) generated or partly generated by an AI model, or (d) something else? If (c), capture model name, date, and prompt summary.
3. **Source.** What named archive, repository, publication, or instrument produced it? "Unknown" is a valid answer and forces a lower category.
4. **Verifiability.** Can a third party retrieve this same document today? If yes, how (catalog ID, URL, archive box reference)?
5. **Claim weight.** What does the user expect this document to prove or support? List the specific claims.

After the intake, produce a classification block in this exact format:

```
---
Document: <name>
Type: <type>
Status: <category from evidence-discipline skill>
Source: <named archive or "—">
Provenance: <origin description; for AI material include model + date + reviewer>
Notes: <one-line working assessment>
---
```

**Discipline checks before you emit the block:**

- If origin is (c) AI-generated, status ceiling is `fabricated` unless every factual element has been independently re-sourced — in which case explain which elements survived.
- If origin is "unknown" or unverifiable, status ceiling is `partial`.
- If the user's claim weight (Q5) exceeds what the category supports, name the gap explicitly. Example: "This is `partial`, which supports 'consistent with' framings but not 'establishes that' framings."

End with a one-sentence next action: what archive or source would upgrade this document's status, drawn from the skill's archive-target list when applicable.
